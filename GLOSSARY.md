# Glossary

**Day type.** Weekday, Saturday or Sunday, taken from the timetable Metro ran on a date. A holiday with Sunday service is a Sunday.

**Departure pattern.** One scheduled bus departure that repeats across days, named by route, direction, day type and start time. It survives timetable changes that rename trip ids.

**Egress.** Data that leaves Google Cloud for a machine outside it, such as a laptop. Google bills it per gigabyte.

**Egress guard.** The check that stops the pipeline from downloading the raw archive to a machine outside Google Cloud.
