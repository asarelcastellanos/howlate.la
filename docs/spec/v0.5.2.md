# Spec v0.5.2

Status: approved 2026-11-24. Grill record: [reach v0.6.0](../grill/2026-11-24-reach-v0.6.0.md). The egress guard has its own record, [egress guard](../grill/2026-11-24-egress-guard.md).

## Goal

After this version the owner can trust the rail numbers on howlate.la, because rail vehicles are matched to the timetable by where they were and when, not by a trip id the feed gets wrong. The pipeline can no longer run up an egress bill from a laptop, and the README states the measured monthly cost. v0.6.0, the commute tool, is the next version to build.

## How to read a claim

Each claim is one testable sentence. "I said" quotes the grill record, as `Q<n>, <answer>` where the owner picked an option. "Proof" says how the claim is shown to work. "Assumes" lists the assumption IDs the claim depends on. QA proves each claim in a real session and posts the evidence in one comment on the issue PR, with `gh pr comment --attach`. QA writes no evidence folder in the repo.

Each feature names the GitHub issue that holds its full done-when list. #164 and #180 merged into `release/v0.5.2` before this spec and carry no claims here.
