## Risks

- **The matcher agrees too rarely with known-good ids.** It does not ship. #166 records the 1,133 trips as impossible, the rail figures keep their footnote, and v0.5.2 releases with the check and the cause only.
- **The guard reads the daily Cloud Run job as outside Google Cloud.** The first daily run after the release fails and healthchecks.io alarms. The next run grades the missed day, because `daily` grades the last seven days. The fix is a revert on `main`.
- **VM spend passes $5.** A full pass over the archive pays about $1.70 in Coldline retrieval. Work stops and I ask the owner before a run that would pass the limit.
- **The four problem days turn 30 days old.** From 2026-12-07 each read of 2026-11-07 pays the Coldline fee. Features 4 to 6 use those days and should finish before then.
- **Spot reclaims the VM mid-run.** A `backfill` run resumes on the next start. A script run starts over, so scripts work one day at a time and save output per day.
- **#177 finds that positions cannot rebuild a run.** The matcher in feature 5 has no ground truth. Work stops and I ask the owner how to proceed.
- **An agent downloads the archive anyway.** The guard refuses, and `CLAUDE.md` forbids `--allow-egress`. The rule reaches `main` only when v0.5.2 releases, so sessions on `main` before then do not see it.
